# 🤖 Build with AI

The original Webstudio AI assistant has been discontinued. Use [Webstudio MCP](mcp.md) when you want an AI agent to build or edit a real Webstudio project. The agent and the visual Builder operate on the same project, so you can review and continue every change visually.
